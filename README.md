# calendario tech

Landing del calendario comunitario de eventos tech y emprendimiento de Mendoza.

## Stack

- Vite + React + TypeScript
- [Motion](https://motion.dev/)
- Embeds: Luma + Google Forms

## Desarrollo

```bash
npm install
npm run dev
```

Copiá `.env.example` a `.env` si necesitás cambiar URLs.

## Scripts

- `npm run dev` — servidor local
- `npm run build` — build de producción
- `npm run preview` — preview del build
